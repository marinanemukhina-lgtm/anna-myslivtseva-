## Шрифты

Cormorant Garamond (прямое начертание 500) и Inter (400, 500), кириллица и латиница, поставляются локально через Fontsource. Лицензия обоих — SIL Open Font License 1.1. Полные тексты включены в `licenses/`.

Cormorant Garamond заменяет PS Times, Inter заменяет Basel Grotesk: исходные коммерческие файлы шрифтов Odyssee не включены. Кириллическая гарнитура близка по характеру, но не тождественна оригиналу.

## Референс

Odyssee Clinic исследован как визуальный ориентир. Его фотографии, видео, фирменный знак, коммерческие шрифты, медицинские тексты, исходный JavaScript и CSS не включены в дистрибутив. Реализация написана самостоятельно. Зависимости npm сохраняют собственные лицензии; их версии закреплены в `package-lock.json`.

## Живой портрет

`anna-portrait-smile.png` — редактирование предоставленного профессионального портрета встроенным imagegen. Улыбка взята с предоставленного снимка Анны с цветком; размер 1122 × 1402. Это не 8K.

`anna-portrait-smile.mp4` — исходная AI-анимация PixVerse V6 Image, 5.04 с, фактический размер 832 × 1024 (заказан тариф 540p), H.264, без звука. Это синтетическая анимация фотографии, не реальная видеозапись Анны.

`anna-portrait-loop.mp4` — короткая зацикленная версия с мягким переходом. Используется только для стандартного портрета. Пользовательский новый портрет из админ-панели автоматически отключает это видео. Кнопка паузы, reduced-motion и остановка вне экрана поддерживаются.

`anna-portrait-calm.mp4` — версия для первого экрана, замедленная в 2,2 раза с интерполяцией до 30 кадров/с. `anna-portrait-eyes.png` — отдельный портрет с чуть увеличенными глазами; сохранён для следующей генерации, в текущем видео глаза не изменены.

## Цветокоррекция видео сеансов

`anna-session-neutral-01.mp4` и `anna-session-neutral-02.mp4` — локальная цветокоррекция предоставленных роликов: зелёная обивка и бордовая форма приведены к нейтральной палитре, яркость второго ролика повышена. Движения, руки, пациент и устройство помещения не заменены. Синтетический интерьер из отдельного эскиза в видео не применён.
