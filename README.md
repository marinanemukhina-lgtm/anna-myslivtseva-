# Анна Мысливцева — сайт и панель управления

Самостоятельный русскоязычный сайт на React с серверной панелью управления. Визуальный ориентир — [Odyssee Clinic](https://www.odysseeclinic.com.au/): композиция, сетка, спокойная типографика, полноэкранные медиа, раскрывающееся меню, смена слайдов и движение элементов при прокрутке.

Использованы предоставленные фотография Анны и два видео. Неизвестные сведения оставлены пустыми. В проекте нет выдуманных услуг, медицинских квалификаций, результатов лечения, цен или контактов.

## Доработанная версия

Крупный двухстрочный титул, контрастная постоянная навигация, локальные Cormorant Garamond и Inter, редакционные блоки, отдельная страница `/diplomas` с прямым входом с первого экрана. На главной сохранены большие видео, слайдер и длинная последовательность разделов; добавлены отдельный блок образования и ссылки на новости/акции.

На первом экране — живой портрет с улыбкой, замедленный в 2,2 раза; доступна остановка движения. Видео массажа приведены к нейтральной палитре. Полная замена интерьера пока не выполнена. Дипломы не выдуманы: раздел ждёт загрузки реальных файлов.

## Быстрый запуск

Нужен Node.js 22.13 или новее; для разработки и CI рекомендуется Node.js 24.

```sh
npm ci
npm run setup
npm run dev
```

Откройте `http://localhost:4173`. Панель: `http://localhost:4173/admin`.

Команда `setup` попросит придумать пароль длиной от 12 символов. Ввод скрыт; в `.env` сохраняется только хеш. Общего пароля по умолчанию нет. Если настройка пропущена, сайт работает, а вход в панель недоступен.

Для локальной работы не нужен внешний сервис: изменения и загруженные файлы хранятся в `.data/content.sqlite`. После перезапуска они сохраняются. `.data` и `.env` не входят в Git. Для резервного копирования локальной версии остановите сервер и скопируйте весь каталог `.data` в защищённое место.

Собранная версия:

```sh
npm run build
npm start
```

## Что редактируется в панели

| Раздел        | Возможности                                                                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| О себе и сайт | Имя, специализация, тексты главной страницы, биография, квалификация, фото и положение кадра, контакты, часы приёма, ссылки, документы сайта |
| Услуги и цены | Название массажа или другой услуги, описание, стоимость, длительность, категория, фотография                                                 |
| Новости       | Заголовок, дата, текст, фотография                                                                                                           |
| Акции         | Предложение, цена, срок, условия, фотография                                                                                                 |
| Дипломы       | Название, учебное заведение, год, описание, изображение или PDF                                                                              |

У записей есть черновик, публикация, изменение порядка и удаление. Сначала внесите изменения, затем нажмите «Сохранить». Галочка «Показывать на сайте после сохранения» определяет видимость записи. Дата новости — подпись, а не отложенная публикация. Срок акции отображается посетителю; снять завершившуюся акцию можно той же галочкой.

Файлы: JPG, PNG, WebP, для дипломов также PDF; до 3 МБ на файл. Встроенные видео находятся в `public/media/` и заменяются при обновлении исходников. Панель рассчитана на одного владельца, без регистрации посетителей и сбора медицинских данных.

Чтобы заменить главное фото: «О себе и сайт» → «Главная фотография» → «Заменить файл» → «Сохранить изменения». Параметр положения кадра позволяет настроить обрезку. Исходная фотография включена в проект.

## GitHub

Репозиторий проекта: https://github.com/marinanemukhina-lgtm/anna-myslivtseva-. Не загружайте `.env`, `.data`, `node_modules` и `dist` — они уже исключены в `.gitignore`. `package-lock.json` включён для воспроизводимой установки.

В `.github/workflows/ci.yml` подготовлена проверка API и сборки на Node.js 24. Инструкция подключения репозитория к Vercel приведена ниже.

## Vercel

Проект включает `vercel.json` и серверную точку входа `api/index.mjs`.

1. Импортируйте GitHub-репозиторий в Vercel. Корень проекта — эта папка, Framework Preset — **Other**, Build Command — `npm run build`, Output Directory — `dist/client`. Выберите Node.js 24.
2. Подключите Neon Postgres. В переменную `DATABASE_URL` добавьте строку подключения Neon. Сервер использует HTTP-драйвер Neon; произвольный обычный PostgreSQL-сервер без этого интерфейса не подходит.
3. Локально выполните `npm run setup`. Скопируйте значение `ADMIN_PASSWORD_HASH` из `.env` в одноимённую переменную окружения Vercel. Сам пароль в GitHub или Vercel добавлять не нужно.
4. Добавьте обе переменные для нужного окружения. Для Preview используйте отдельную базу или ветку Neon, чтобы проверка не меняла рабочий сайт.
5. Выполните Deploy. Таблицы создаются при первом обращении к API. Откройте `/admin`, войдите, внесите реальные сведения и сохраните.

Без `DATABASE_URL` на Vercel доступна исходная публичная версия сайта, а панель сообщает, что настройка не завершена. Без хеша пароля вход закрыт. Локальные данные SQLite не переносятся в Neon автоматически: при первом размещении база содержит только исходное имя, фотографию и пустые разделы.

Тексты, сессии и загруженные изображения/PDF хранятся в Postgres, поэтому сохраняются между вызовами Vercel Functions и повторными размещениями. Видео из исходников обслуживаются как статические файлы. Резервное копирование рабочей базы настраивается в Neon.

После размещения проверьте вход и выход, создание черновика, публикацию, загрузку диплома, открытие прямой ссылки на новость и отображение на телефоне. Облачная база и реальное размещение требуют подключения ваших учётных записей; в этой поставке проверен локальный сервер с SQLite, сборка и браузерные сценарии.

Официальные справки: [Vercel Functions](https://vercel.com/docs/functions/runtimes/node-js), [маршрутизация Vercel](https://vercel.com/docs/routing/rewrites), [Neon serverless driver](https://neon.com/docs/serverless/serverless-driver).

## Страницы и поведение

Главная, услуги и цены, об Анне, новости, отдельная новость, акции, отдельная акция, дипломы с просмотром, контакты, конфиденциальность, условия использования, панель администратора.

Меню закрывается по Escape и клику на фон, удерживает фокус и возвращает его на кнопку открытия. Слайдер поддерживает нажатия, автоматическую смену, свайп и паузу при наведении/фокусе. Видео воспроизводятся без звука в видимой области. Учтена настройка уменьшения движения; в подвале есть ручной переключатель анимации. На компьютере список из 2–6 услуг меняет активный пункт при прокрутке и по нажатию; более длинный список, мобильная версия и режим без анимации используют раскрытие по нажатию.

## Исходный код

- `src/App.jsx`, `src/styles.css` — публичные страницы и анимации.
- `src/Admin.jsx`, `src/admin.css` — управление содержимым.
- `shared/content.mjs` — схема и исходные данные.
- `server/app.mjs`, `server/db.mjs` — API, авторизация, хранение.
- `api/index.mjs`, `vercel.json` — размещение на Vercel.
- `public/media` — локальные фотографии, видео и постеры.
- `tests/api.test.mjs` — настоящие HTTP-запросы к временному хранилищу.
- `ASSETS.md`, `licenses/` — происхождение материалов и лицензии шрифтов.
- `design-qa.md` — визуальная проверка и ограничения точности.

Служебные файлы `.openai/hosting.json`, `worker/`, `scripts/prepare-sites-build.mjs` и `tests/sites-worker.test.mjs` сохранены от шаблона предпросмотра. Этот статический worker не заменяет Express API: для полноценной панели используйте Vercel или `npm start`.

## Проверка

```sh
npm test
npm run test:sites
npm run build
```

API использует серверные сессии с HttpOnly-cookie, проверку Origin, ограничение попыток входа, валидацию содержимого и типов файлов. Черновики и их вложения недоступны посетителям. Одновременное редактирование в разных вкладках обнаруживается по версии документа.
