Hallmark вернул **161 FAIL, 276 REFLEX, 14 WARN** в 451 уникальном замечании по файлам и измеренным страницам. Метки FAIL/REFLEX — **классы внутренней методики Hallmark**, а не 161 доказанная поломка сайта. Не применять все автоматически.

## Как повторить

В GitHub Actions запустить `Hallmark site design audit` по ветке `audit/hallmark-anna-20261101` или после включения workflow в основную ветку. Сценарий `.github/workflows/hallmark-audit.yml` скачивает **фиксированную версию** Hallmark, запускает проект на временном локальном QA-сервере, устанавливает Puppeteer и Chromium во временном GitHub runner, выполняет `sloplint --before --json --url` и сохраняет скриншоты и JSON.

**Граница установки:** этот workflow подключает Hallmark к *проекту и проверке в GitHub*. Он **не устанавливает** новый системный навык в текущий аккаунт ChatGPT. Для постоянной регистрации в ChatGPT нужен отдельный канал установки навыков, отсутствующий среди доступных действий. Код источника не копируется в приватный репозиторий.
