## Наблюдаемые проблемы, упорядоченные по значимости

1. **P1 / мобильное переполнение**: `/about` при ширине 320px имеет `scrollWidth=336px`, то есть горизонтальный выход на 16px. Hallmark: FAIL 34. `src/styles.css` содержит четыре использования `100vw` для меню (строки 191, 1380, 1687, 1835), но причинность каждого совпадения не доказана. Нужно найти конкретный элемент, затем убрать переполнение без обрезания интерактивных элементов.
2. **P1 / читаемость**: главная, подпись «ОСТЕОПАТ» на 1280px: измеренный контраст примерно **2,11:1** против порога 4,5:1 для обычного текста. Hallmark: FAIL 40. Провести сверку на исходной фотографии и всех состояниях видео; возможная коррекция — подложка/градиент или иной контрастный участок, без изменения изображения Анны.
3. **P1 / доступность клавиатуры, требует перепроверки**: 11 срабатываний FAIL 26a на ссылке пропуска к содержимому, ссылке «Запись на приём» и кнопке оживления портрета. Для них Hallmark измерил контраст фокус-кольца от 1:1 до 1,26:1. Проверить программно- и вручную-сфокусированные состояния на светлом хедере и поверх портрета, затем корректировать `:focus-visible` точечно.
4. **P2 / мобильные действия**: на пяти страницах Hallmark заметил высоту части кнопок около 19px, у кнопки портрета — 38px (REFLEX 39b). Увеличивать область попадания нужно после проверки реальной геометрии, сохраняя внешний вид.
5. **P2 / сопровождение**: 83 литерала цвета вне токенов (FAIL 48), особенно в `admin.css`. Стоит унифицировать только при согласованном техническом рефакторинге. Нельзя трактовать наличие `white` как неисправность дизайна.
6. **P3 / стилевые маркеры**: подписи `.eyebrow`, заглавные буквы и нестандартные отступы — часть утверждённой визуальной системы, вдохновлённой Odyssée. Hallmark предлагает их убрать, но приоритет сохраняет ранее согласованное направление из `AGENTS.md`.

### Что уже хорошо

На снимках сайта видны индивидуальная фотография Анны, крупная кириллица, спокойная палитра и самостоятельные композиции страниц. Связи, маршруты, видео, форма контактов и система администрирования не должны заменяться автоматическим шаблоном. Hallmark не даёт объективного числового показателя «сайт выглядит как ИИ», а его количества FAIL не являются UX-оценкой.

## Интеграция и границы

Файл `.github/workflows/hallmark-audit.yml` обеспечивает **повторяемый запуск** Hallmark в GitHub Actions по команде на ветке: закреплён исходный commit, ставится временная браузерная зависимость, запускается локальный сервер с синтетическими данными, готовятся изображения и отчёт. Это интеграция в кодовый проект, **не глобальная установка навыка в аккаунте ChatGPT**. Статус `render: ran` проверен фактически.

Ничего из перечисленного не исправлялось автоматически. Ветки `main`, PR №5 и №6, работающий Vercel и данные пользователей не изменены этим аудитом. Любые правки визуала должны пройти сравнение до/после, CI и отдельный допуск к публикации. Механические замечания Hallmark необходимо согласовывать с уже принятым проектным направлением.
