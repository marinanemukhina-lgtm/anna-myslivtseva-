Сохранены мастерская, редакторская проверка, карточки тем, состояния draft/ready/scheduled/published, календарь и ручные замеры, импорт/экспорт JSON. Изменены подписи книги на темы и направления «услуги / запись». Имена внутренних полей сохранены для совместимости. Книга, посты, личные данные, реальные identity и credentials не скопированы. Начальное состояние содержит 12 редактируемых карточек по подтверждённым названиям программ, без готовых постов, лечебных обещаний и утверждений о конкретных сертификатах.

Страница `/admin/marketing` и все её API требуют парольной сессии. Временный редактор материалов не получает доступ. Локальное имя базы `anna_warmup_channel_v4` изолировано. Отдельная кнопка сохраняет серверную копию в строке `content.id=marketing`; это не публикация. Версия защищает от потери данных между вкладками. При существующей локальной базе сначала нужен экспорт и явная загрузка сервера. Локальное автосохранение остаётся функцией исходной мастерской; на общем устройстве не хранить конфиденциальные данные. Серверная копия не содержит ключей публикации. После выхода из панели доступ к серверу прекращается, локальная база остаётся в браузере.

## Честные границы

Исходный контур прямо не включает live publish. Готовых адаптеров автопостинга и плана Hormozi в исследованных исходниках не найдено. Они не выдумываются. Отметка «Опубликован» фиксирует уже размещённый материал по ссылке, а не отправляет его. Endpoint publish возвращает 503. Аккаунты не создавались, постоянные доступы не выдавались, публикации не выполнялись.

- Telegram: https://core.telegram.org/bots/api
- MAX: https://dev.max.ru/docs-api/use-cases/bot-in-chats-and-channels/
- Instagram: https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api
- WhatsApp: https://www.postman.com/meta/whatsapp-business-platform/collection/wlk6lh4/whatsapp-cloud-api

Для WhatsApp Status официальный endpoint не подтверждён. Ручной экспорт базы не равен подготовленному медиафайлу для Stories. Для рекламы в Instagram в РФ действуют ограничения; материал нельзя считать допустимым автоматически. Telegram и MAX также требуют проверки требований к рекламе. Медицинские утверждения, квалификация и услуги должны быть подтверждены, обещания гарантированного результата недопустимы; применимость ст.24 закона о рекламе проверяется перед размещением. Исходная редакторская проверка не заменяет медицинскую и правовую экспертизу.

Поставка подготовлена локально. Перед выпуском: интегрировать две строки server/app.mjs и ссылку Admin.jsx с актуальным PR10, запустить тесты на итоговой версии и проверить Vercel preview. Sites worker не изменялся и не реализует этот приватный Node API.

## Уточнение содержания

В центре каждого поста — полезное объяснение самой темы. Соответствующий подтверждённый диплом кратко упоминается в конце как подтверждение подготовки. История о мотивации Анны учиться и процессе обучения в план не входит. Не заполнять сведения о дипломах без проверенного источника.

## Проверки интеграции

Мастерская интегрируется отдельно от календаря: она использует собственную запись marketing и всегда требует настоящую сессию владельца, даже когда рабочие часы временно открыты. Автопостинг и привязка аккаунтов запрещены сервером.

При переносе усилена проверка импорта: рабочие черновики проверяются так же, как посты, а неизвестные вложенные поля отклоняются целиком без изменения исходного файла. Поддерживаются известные форматы v3/v4; неподдерживаемые расширения не удаляются молча. Рабочий черновик восстанавливается при первоначальной загрузке серверной копии. Изменение черновика соседней вкладкой приостанавливает сохранение, чтобы пользователь мог отдельно сохранить свой текст.

До выпуска остаётся выполнить браузерные сценарии на итоговом коммите. Локальная сборка и серверные проверки не заменяют проверку интерфейса.

## Обновление 6 ноября: доступ из открытой админки

По уточнению пользователя маркетинговая мастерская доступна через тот же временный доступ к материалам на точном production-домене; вне этого режима нужна сессия владельца. Ссылка возвращена в верхнюю часть панели. Соцсети имеют отдельный редактор ссылок. Учётные данные не принимаются, автопубликация остаётся выключенной.

Страница «Материалы и план» читает описание, ссылки и дипломы из CMS, показывает восстановленное описание из GEO-пакета 4 ноября и новый рабочий проект последовательности материалов по существующим 12 темам. Проект не объявляется прежним утверждённым планом. Сканы дипломов и точные адреса аккаунтов в доступных источниках не найдены; чужие документы и данные одноимённых специалистов не перенесены.

Открытие маркетинга больше не создаёт строку marketing. Начальное состояние возвращается для просмотра; первая явная запись выполняется кнопкой сохранения с защитой от конфликта версии. Существующие серверные и локальные черновики сохраняются. Реальная база при подготовке этой правки не редактировалась. Подготовленное описание переносится только в пустые поля редактора по отдельной кнопке; публикация требует обычного сохранения CMS.
