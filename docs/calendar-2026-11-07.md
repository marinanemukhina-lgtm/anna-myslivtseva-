Основа ветки: опубликованный main d37630287496752ca94167b6f595a279cdc7c758 и редакционный черновик PR25. Календарные компоненты выборочно перенесены из PR20. * Mode week/month, Monday–Sunday date arithmetic, prev/next and today navigation, shared selected date with existing day override editor.
* Existing authenticated occupancy GET feeds only aggregate active busy interval counts, not names. Counts are hidden for temporary/open schedule editors; zero is NOT proof of confirmed free slots.
* Existing CAS/write APIs, time zone editing, appointments data privacy and disabled public booking remain unchanged. No patient data collected by this feature.
* Added Node tests for date/period/status and browser smoke for calendar navigation. CI and visual QA are release gates, not assumed.
* Нет merge и публикации. Для integration/anna-editorial-calendar-20261111 автоматическое развёртывание выключено.
* Owner-only internal reserve added using the existing authenticated CAS endpoint. A live GET rechecks freshness and service/date/slot before owner confirmation and POST. POST carries opaque operation key and no patient data; uncertain writes are not blindly retried. Actual personal booking/notifications remain disabled.
