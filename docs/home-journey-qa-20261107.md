## Дополнительные тематические источники

Использовано подтверждённое исследование родителя, без самостоятельной проверки live UX этих двух сайтов:

- [Tangan, Site of the Day](https://www.awwwards.com/sites/tangan): кадры рук в работе и редакционная типографика поддерживают сохранение собственных материалов Анны и существующего типографического характера. В изученных родителем desktop/mobile материалах действие записи на первом экране не видно; эту слабость не повторяем: у Анны есть явный CTA контакта.
- [Kalm Moments, Honorable Mention](https://www.awwwards.com/sites/kalm-moments): ясные услуги и способы связи поддерживают основной контакт и дополнительный CTA услуг только при наличии опубликованного каталога. Это Honorable Mention, не Site of the Day.

Марина уточнила: Kalm Moments ближе Анне по настроению; чёрно-белая стилистика Tangan для Анны не подходит, допустимы только отдельные идеи. Из Aventura одобрены выразительность и контакт, из HEVA — спокойствие и ясный путь, из Maxima — структура процесса без детского визуала. Эти уточнения не меняют согласованную визуальную концепцию. Чёрно-белая обработка, чужие фотографии, цены и награды не переносятся на сайт Анны.
