# Научные материалы Анны Мысливцевой — редакционный процесс

Дата начала: 1 ноября 2026 года. Статус: **черновики, не опубликованы**.

## Назначение

Подготавливать понятные русскоязычные статьи о результатах открытых исследований и рекомендациях, представляющих интерес посетителям сайта. Пересказывать выводы своими словами, сохраняя исходные сравнения, популяции, оценки уверенности, риски, ограничения и даты поиска литературы. Не создавать личные истории пациентов, фотографии «до/после», отзывы или утверждения об эффективности услуг Анны на основании чужих исследований.

## Рабочий контур (без автоматической публикации)

1. Поиск открытой статьи, руководства или проверяемого резюме исследования. Проверка DOI, авторов, даты, оригинальной страницы, доступности и последующих обновлений; для Cochrane отдельно отмечать, что доступен публичный реферат, когда полный текст недоступен.
2. Черновик простым русским языком: что изучали, с чем сравнивали, сколько человек, чего удалось достичь, что неизвестно. Контролировать точность чисел и отсутствие обобщений на всех пациентов.
3. Сверка с источником и человеком, обладающим соответствующей квалификацией. Отдельное редакционное утверждение медицинского содержания перед публикацией.
4. Авторизованный администратор импортирует материалы через вкладку **Новости** → **Загрузить научные статьи в черновики**. Импорт повторяемый, не дублирует записи, выполняется в существующей CMS; при параллельной записи возвращает конфликт версий.
5. Материалы сохраняются с published=false. Общий флажок публикации заблокирован для этих трёх исходных черновиков на сервере и в интерфейсе; дальнейшее утверждение/релиз требует отдельного подтверждённого действия.
6. Только после согласования: подготовка дат, SEO-проверка, отслеживание фактического появления в индексе Яндекса. Частота выхода не определена и не должна подменять медицинскую проверку. Автоматическая публикация в PR отсутствует.

## Критерии приёмки

- Импорт доступен только после входа в админку, запросы из чужого Origin отвергаются.
- Нельзя импортировать произвольный медицинский текст через служебный endpoint: ID ограничены перечнем трёх черновиков.
- Импорт не перезаписывает существующие записи и не повышает статусы опубликованности.
- Сведения черновиков недоступны публичным API, карте сайта и странице «Новости».
- Сервер отвергает попытку опубликовать научный материал без отдельно реализованного медицинского утверждения.
- Не отправлять материалы в рабочий Vercel deployment и не изменять production-данные без отдельного разрешения.

### Команды проверки

npm test
npm run build
npm run test:sites
npm run test:browser

Проверить результаты по конкретному commit SHA в GitHub Actions. Зелёный CI подтверждает исполнение кода на тестовых данных, но сам по себе не подтверждает корректность всех клинических интерпретаций и не заменяет медицинское заключение.
